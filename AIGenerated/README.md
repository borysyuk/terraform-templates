# AIGenerated

Terraform/OpenTofu/Terragrunt fixtures generated by Claude Code for exercising Scalr features on
testenvs. None of them needs cloud credentials: they use only the `null`, `local`, and built-in
`terraform_data` resources. Keep them; they are meant to be reused.

| Folder | Purpose | How to use in Scalr |
| --- | --- | --- |
| `drift/local-file` | Workspace that shows drift on every drift-detection check: `local_file` lives in the run container, which is gone by the next run. | VCS workspace with working directory `AIGenerated/drift/local-file`, apply once, then enable a drift-detection schedule for the environment. The report lands in `awaiting_manual_action`. |
| `modules/terraform-null-inputs-demo` | Registry module with required, optional, and sensitive inputs, `count`-based resources, outputs, a README, and a submodule. | Publish from VCS with path `AIGenerated/modules/terraform-null-inputs-demo` and tag prefix `aigenerated-inputs-demo/`. Versions are tags such as `aigenerated-inputs-demo/v1.0.0`. |
| `terragrunt/run-all-basic` | Two Terragrunt units (`network`, `app`) where `app` depends on `network`. | Terragrunt workspace (needs the account Terragrunt integration) with working directory `AIGenerated/terragrunt/run-all-basic`, `use-run-all` on, remote backend off. |

Tags created for these fixtures use the `aigenerated-` prefix so they never mix with the
repository's other version tags.
